### Bug 修复：设置/日程页面一直转圈打不开

- settings_screen.dart 从 StatelessWidget 改为 StatefulWidget，loadOverrides() 移到 initState
- schedule_screen.dart 同样将 loadOverrides() 移到 initState

### UI 改造：闹钟时间选择器改为滚轮滑动

- 铜色半透明 selectionOverlay，品牌视觉一致
- 编辑闹钟时正确初始化到已有时间

### QA 验证

- flutter build apk --debug 编译通过

### Bug 修复：节假日 API 无法同步
- 根因1：User-Agent 设为 `ZhanMaAlarmClock/1.0`，Cloudflare 不认非浏览器 UA → 403
- 修复1：改为模拟 Android Chrome 的标准 UA
- 根因2：日期 key 解析用 `split('.')` 但 API 实际返回 `01-01`（横杠分隔）格式
- 修复2：改为 `split('-')`
- API 端到端验证通过（HTTP 200 + 正确 JSON 数据）

### Bug 修复：单双休切换不了
- 根因：ScheduleStorageService.init() 自己用 `openDatabase('alarm_clock.db', version: 1)` 打开了一个独立数据库，而 AlarmStorageService 用 `$path/alarm_clock.db` version: 4，两个 DB 完全脱节
- 修复：ScheduleStorageService 改为共享 AlarmStorageService 的数据库实例（setDatabase 模式），和 HolidayService 一样
- main.dart 中去掉独立的 ScheduleStorageService.init() 调用

### 第8轮：5个Bug批量修复

#### Bug1: 熄屏时闹钟不显示全屏提示
- 修复：AlarmRingingService fullScreenIntent Intent 加 FLAG_ACTIVITY_CLEAR_TASK
- 修复：alarm_notification_service.dart AndroidNotificationDetails 加 fullScreenIntent: true

#### Bug2: 锁屏后倒计时不在后台运行
- 根因：TimerProvider 用纯 Dart Timer.periodic，后台/Doze 被暂停
- 修复：添加 _endTime 绝对时间，start 时通过 TimerBackgroundService(MethodChannel) 安排原生 AlarmManager 精确闹钟
- 新建 timer_background_service.dart（MethodChannel 通信）
- 新建 TimerReceiver.kt（接收广播、播放声音、发通知）
- timer_screen.dart 添加 WidgetsBindingObserver，resumed 时 syncFromEndTime()
- MainActivity.kt 添加 timer_background MethodChannel handler

#### Bug3: 倒计时预设按钮不更新界面数字
- 根因：CupertinoTimerPicker.initialTimerDuration 是初始化参数，变更不更新
- 修复：TimerPicker 加 key: ValueKey(_pickedDuration) 强制重建

#### Bug4: 选工作日但周六还响
- 根因：shouldRingOnDate 中 RepeatType.once 直接返回 true 忽略 weekdays
- 修复：once 类型检查 weekdays 字段；RepeatPicker onChanged 自动推断 repeatType（1-5→weekdays, 6+7→weekends, 全7天→daily, 其他→custom）
- _WeekTypeDropdown 增加 weekdays 和 custom 选项

#### Bug5: 杀后台后闹钟不自启动
- 修复：BootReceiver 增加 LOCKED_BOOT_COMPLETED/QUICKBOOT_POWER/MY_PACKAGE_REPLACED 等 intent-filter
- 修复：AlarmRescheduleWorker 改用 callback-based 等待替代 Thread.sleep
- 修复：AlarmRingingService.onTaskRemoved() 中 enqueue AlarmRescheduleWorker
- 修复：MainActivity.initWorkManager() 手动初始化 + 6小时 PeriodicWorkRequest 定期检查

#### QA: 17项验证点全部 PASS，编译通过

### 第9轮：全屏闹钟界面修复 + 响铃周期精简

- 修复3：MainActivity.kt checkAlarmLaunch 加 500ms 延迟重试（最多3次）
- 修复4：AlarmRingingService.kt fullScreenIntent 去掉 FLAG_ACTIVITY_CLEAR_TASK（会清空任务栈导致 Flutter 状态丢失）
