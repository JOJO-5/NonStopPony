# 2026-05-23 Working Log

## 战马闹钟 — 第六轮：法定节假日同步 + 单双休联动算法

### 需求
1. 自动同步国家法定节假日数据，假期不响、补班日响
2. 单双休切换单双休联动：手动切换某周后，后续周自动推算
3. 日历上直观标注假期和补班日

### 核心改动

#### 1. 法定节假日服务 (`HolidayService`)
- 新建 `lib/services/holiday_service.dart`
- 调用 timor.tech API 拉取中国法定节假日数据
- 本地缓存到 SQLite `holiday_cache` 表
- DB 版本 v3→v4，onUpgrade 自动建表
- 提供 `isHoliday(date)`/`isWorkday(date)` 查询
- 启动时自动同步当年+次年数据（非阻塞）

#### 2. 单双休联动算法重写
- `WeekSchedule` 模型新增 `weekIndex` 字段（绝对周序号）
- `resolveWeekType` 改为链式联动：
  - 每个 override 是"锚点"
  - 锚点之间的周自动交替 单↔双
  - 锚点之前没有 override → 奇偶周
- 手动切换某周后，后续周自动重新推算
- 移除旧的 `_findNextWeekday`/`_findNextWeekend` 方法

#### 3. 闹钟调度融合节假日判断
- `shouldRingOnDate` 新增 `isHoliday`/`isWorkday` 参数
- 节假日 → 不响，补班日 → 响
- `AlarmSchedulerService.calculateNextTrigger` 逐日查询节假日状态
- `ScheduleStorageService` 新增 `getByWeekIndex`/`deleteByWeekIndex`

#### 4. UI 更新
- `WeekScheduleCalendar` 日历显示假期（绿色底+休字）和补班日（橙色底+班字）
- 设置页新增"法定节假日"同步区域
- 首页日期旁显示今日假期/补班标记
- 底部 sheet 提示"切换后，后续周将自动联动调整"

### 修改的文件
- **新建** `lib/services/holiday_service.dart`：节假日数据服务
- **重写** `lib/utils/date_utils.dart`：联动算法+节假日融合
- **重写** `lib/models/week_schedule.dart`：新增 weekIndex
- **重写** `lib/providers/schedule_provider.dart`：链式联动逻辑
- **重写** `lib/widgets/week_schedule_calendar.dart`：节假日标记UI
- **修改** `lib/services/alarm_storage_service.dart`：DB v4 + holiday表
- **修改** `lib/services/alarm_scheduler_service.dart`：节假日判断
- **修改** `lib/services/schedule_storage_service.dart`：weekIndex 字段
- **修改** `lib/main.dart`：HolidayService 初始化
- **修改** `lib/screens/settings_screen.dart`：节假日同步区域
- **修改** `lib/screens/alarm_list_screen.dart`：今日假期标记

## 战马闹钟 — 第十轮：计时器全屏提醒 + 上划关闭 + 日程显示Bug

### 需求
1. 计时器锁屏提醒只有通知，没有像闹钟一样的全屏界面
2. 闹钟和计时器都加上上划关闭手势
3. 手动改了日程双休，但闹钟界面仍显示"本周单休"

### 核心改动

#### 1. 计时器锁屏全屏提醒（TimerRingingService）
- **新建** `TimerRingingService.kt`：参照 AlarmRingingService，前台服务 + fullScreenIntent + 循环铃声 + 振动
- **重写** `TimerReceiver.kt`：不再自己播放声音和显示通知，改为启动 TimerRingingService
- **新建** `lib/screens/timer_fullscreen_screen.dart`：计时器全屏提醒界面，深色主题 + 计时器图标 + 上划关闭
- `MainActivity.kt`：新增 `checkTimerLaunch()` 处理 `timer_ring` extra，添加 `startTimerRing`/`stopTimerRing` 方法
- `main.dart`：新增 `timer_fire` MethodChannel 监听 + `_navigateToTimerScreen()` + pending 缓存机制
- `timer_screen.dart`：计时完成时启动 TimerRingingService + 弹出全屏界面（替代旧的 AlarmNotificationService）
- `AndroidManifest.xml`：注册 TimerRingingService（foregroundServiceType=specialUse）
- `app.dart`：注册 `/timer_ringing` 路由

#### 2. 上划关闭手势
- `alarm_fullscreen_screen.dart`：添加 GestureDetector 垂直拖拽检测 + _swipeCtrl 进度动画 + "上划关闭"提示
- `timer_fullscreen_screen.dart`：同上，上划超过阈值(60%)即触发关闭
- 滑动过程中铜色/橙色遮罩渐显，视觉反馈清晰

#### 3. 日程显示Bug修复
- **根因**：`alarm_tile.dart` 的 `_weekBadge()` 调用 `resolveWeekType(now, [])` 传入空列表
- **修复**：改为 `context.watch<ScheduleProvider>().resolveWeekTypeByDate(now)`
- 现在 alarm_tile 会正确读取用户的覆盖设置，显示"本周双休"

## 战马闹钟 — 第十轮补修：INTERNET权限 + 计时器全屏动画

### 问题
1. 同步法定节假日显示0条 — release APK 缺少 INTERNET 权限
2. 计时器全屏界面动画不统一 — 改为跟闹钟一样的钟表动画

### 根因
- `AndroidManifest.xml`（main）没有声明 `INTERNET` 权限，只有 debug/profile 有
- `flutter build apk` 使用 release 配置，导致网络请求全部失败
- 计时器全屏用的是静态 timer 图标，而闹钟用的是动态钟表 AnalogClockWidget

### 修复
- **AndroidManifest.xml**：添加 `INTERNET` + `ACCESS_NETWORK_STATE` 权限
- **timer_fullscreen_screen.dart**：中心改为 AnalogClockWidget（动态钟表），加 shake 微振效果，配色改为跟闹钟一致的深棕底+橙色点缀
