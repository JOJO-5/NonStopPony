# 暖铜晨光 / 01

本次仅为独立 HTML 交互设计稿，不修改 Flutter 应用。用户要求先看一版，因此提供一个统一方向。

- 来源：lib/app.dart 当前设计 token；上一轮 Android 2.0.8 实测截图位于 tmp/ui-review-20260919。
- Logo：../assets/icon.png，沿用仓库真实战马图标。
- 暖白 #F9F5F0、白色 #FFFFFF、深棕 #2D1B0E、铜色 #B85E32、操作色 #9E4827、分隔线 #EAE0D5。绿色用于休息状态。
- 8px 基础节奏，16–24px 卡片圆角。数字优先 Bahnschrift，中文沿用本机微软雅黑/苹方；展示页介绍使用宋体，应用内维持清晰无衬线。
- 手机近距离阅读；首页突出下一次响铃，新建页固定保存，设置分组，关于页保留温暖叙事。彩蛋为局部轻弹 + 当前视口模态奖励，支持关闭动效及 prefers-reduced-motion。
- 示例数据固定在 2026-09-19，仅用于设计预览，不读取用户数据库，不设置真实闹钟，不改变权限。日期计算、权限检查、调休、通知、铃声播放不在本原型实现范围。
- 可交互：导航、添加/编辑预览闹钟、开关、重复选择、设置状态、折叠诊断、7 次 Logo 点击与奖励关闭、计时预设、秒表开始/暂停/重置。
- 运行：从仓库根目录提供静态 HTTP 服务，访问 /design-demo/；也可以直接浏览器打开 index.html。无外部依赖或 CDN。
